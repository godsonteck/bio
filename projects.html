ALERA Healthcare Platform

A production-grade healthcare management system designed to streamline communication between patients and providers. It features real-time ambulance tracking, role-based access for labs and pharmacies, and a modern, responsive interface.

Key Features
  • Real-time Live Location Tracking for emergency services
  • Role-based Dashboards (Admin, Lab, Pharmacy, Ambulance)
  • Secure Multipart Result Uploads and Management
  • Advanced Data Visualizations with Recharts
  • Responsive Glassmorphism UI/UX Design
Technologies Used
React TypeScript FastAPI WebSockets PostgreSQL Tailwind CSS
Challenge & Solution

Implementing real-time tracking required robust WebSocket synchronization. I developed a room-based streaming architecture to handle patient-responder location updates efficiently across thousands of concurrent users.
